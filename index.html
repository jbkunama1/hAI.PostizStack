hAI.PostizStack

Ziel

Ressourcenschonender selbst gehosteter Social-Media-Automations-Stack mit Postiz, PostgreSQL und Redis.

Stack-Komponenten

  • Postiz (v2.11.3) – AI-gestützter Social-Media Scheduler
  • PostgreSQL 15 Alpine – Datenbank für Metadaten und Zustände
  • Redis 7.2 Alpine – Background-Jobs & Caching

Quick Start

  1. 1. Passwörter generieren – OpenSSL-Befehle für PostgreSQL-Passwort und JWT-Secret
  2. 2. docker-compose.yml anpassen – Domain, Passwörter ersetzen
  3. 3. Deployment – Docker Compose CLI oder Portainer verwenden
  4. 4. Erster Zugriff – URL öffnen, Admin-User anlegen

Ressourcenverbrauch

Container RAM Limit Realer Verbrauch
postiz 512 MB ~300-400 MB
postiz-postgres 256 MB ~150-250 MB
postiz-redis 128 MB ~20-50 MB
Gesamt 896 MB ~470-700 MB

Reverse Proxy

Nginx Proxy Manager oder Cloudflare Tunnel können verwendet werden, um den Stack auf eine öffentliche URL zu leiten.

Upgrade-Pfade

Später kann Phase 3 mit Temporal und Elasticsearch hinzugefügt werden.
